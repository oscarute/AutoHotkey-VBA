# Apps for Windows

## OScript

This script allows to reboot and shutdown using hotkeys in computers where the interface is locked (Kiosk mode).

### Automatic execution
Save the executable file and create a shortcut in your startup folder:
"C:\Users\<UserName>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup".

### Usage
Shutdown: Control + R  
Reboot: Control + S  
Cancel: Control + A

Tip: Once the user has enabled shutdown or reboot has 30 seconds to cancel.

## PPTNotes

Extracts all speaker notes from a PowerPoint presentation into a single `.txt` file, one block per slide, so you can read or rehearse the whole script at once. PowerPoint's own options (Create Handouts, Notes Pages) split the notes across pages and can cut long texts.

The output file `Notes_<presentation name>.txt` is saved in UTF-8 and opened automatically in Notepad:

```
=== Slide 1 ===
Notes of slide 1...

=== Slide 2 ===
(no notes)
```

Requirements: Windows with desktop PowerPoint (Office 2019 or later).

### Option A: batch file (`ExtractNotes.bat`)

No macros, no `.pptm` files and no VBA editor needed.

1. Download `PPTNotes/ExtractNotes.bat`.
2. Use it in one of two ways:
   - **Double-click** it while a presentation is open in PowerPoint. It extracts the notes of the active presentation, even if it has not been saved.
   - **Drag and drop** a `.pptx` file onto it. It opens the presentation in the background (read-only), extracts the notes and closes it. PowerPoint does not need to be open.
3. The `.txt` file is saved in the presentation's folder. If the presentation is unsaved or stored in OneDrive/SharePoint, it is saved on the Desktop.

Notes:
- The first time, Windows SmartScreen may warn about a downloaded file. Right-click the `.bat` → Properties → check **Unblock** → OK.
- The batch file runs an embedded PowerShell script. Some corporate antivirus policies block this; if so, use option B.
- With several presentations open, double-click uses the active one. Drag and drop the file to be sure which one is processed.

### Option B: VBA macro (`ExtractNotes.bas`)

Run the code directly inside PowerPoint.

1. Save the presentation (the output file is created in its folder).
2. Press `Alt + F11` to open the VBA editor.
3. Either:
   - **File → Import File…** and select `PPTNotes/ExtractNotes.bas`, or
   - **Insert → Module** and paste the contents of `ExtractNotes.bas` (skip the first `Attribute VB_Name` line).
4. Place the cursor inside `ExtractNotes` and press `F5`.

Notes:
- The macro finds the notes box by its type instead of `Placeholders(2)`, which fails with *Invalid argument* (error 80070057) on slides without a notes placeholder, such as slides generated by code.
- To keep the macro inside the file you must save it as `.pptm`. If you only need it once, close the VBA editor without saving the module.
